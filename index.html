Mobile APK & Setup Guide

Aap is app ko apne Android phone me **2 aasan tarikon** se install aur use kar sakte hain:

Tarika 1: Direct Mobile Install (Instant)

1. Chrome Browser me yeh link kholen.
2. Chrome menu (⋮) me **"Add to Home screen"** ya **"Install App"** par tap karein.
3. Fast, smooth aur fully offline native app jaisa chalega!

Tarika 2: GitHub + PWABuilder se APK Banana

1. Is code ko `index.html` naam se save karein.
2. GitHub par upload karke **GitHub Pages** active karein.
3. Live link ko [PWABuilder.com](https://www.pwabuilder.com) me daal kar direct **Android APK** generate karke download karein.
